## 2. 差异化卡位（核心卖点）

同类项目没有一个做成"AI 不会忘"的闭环：

- **认知循环**：A库（SQLite自动打标）+B库（笔记）双库 → memtag 七类打标 → 四层漏斗捞取 → 效果回填（effectGain/adoptOf）→ 越用越聪明。
- **任务循环**：立项五问 → 计划闸门（门0/门1）→ 审计代理 → 施工文档制 → 段收账 → DONE 闭环。
- **可携带**：U盘随身，数据不出盘。

一句话 Slogan 候选："那个能记住自己昨天做了什么的 AI 代理——而且你用得越多，智能越高。从U盘运行。"

## 3. 开源什么 / 不公开什么

**开源（核心仓 axiom-one-core）**

- 认知循环：obelisk 打标引擎 + 检索四层漏斗 + 回填机制（SQLite，纯代码，天然可开）
- 任务循环：计划闸门/审计/施工文档 chain 钩子 + test_battery
- 职位系统：agents 注册壳 + 岗位手册模板 + 交接卡 + 信任台账
- 公开版铁律文档（政策层脱敏后反而成卖点——"系统宪法"本身就是稀缺品）

**不公开**

- GUI 桌面端引擎/商业部分、会员信息、技能缓存、二进制产物、私有凭据
- 服务器端分发体系

许可证：Apache-2.0（本赛道主流，含专利保护条款；MIT 为备选）
